A case is one recording with its start time and a rough search area. Create one from an audio file, or render a synthetic recording whose microphone position is known so you can see the whole workflow first.

    spectrogram, tonal lines, curve fits
  2. 2. Flight data
    historical ADS-B for the window and area
  3. 3. Locate the microphone
    blind search, uncertainty, null tests
